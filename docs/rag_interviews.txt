| Interviewer Attack                          | Why It Matters                             | Production-Level Solution                                                                                  |
| ------------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Corpus grows to **10M+ chunks**             | pgvector may slow down                     | Use **HNSW index**, shard by `video_id`, or migrate to dedicated vector DB (Milvus / Weaviate / Pinecone). |
| **Embedding model changes**                 | Old embeddings become incompatible         | Add **embedding_version** column + run background **reindex pipeline**. Switch search to latest version.   |
| **Duplicate videos** from Telegram          | Causes duplicate chunks and wasted compute | Extract **YouTube video ID** and enforce `UNIQUE(video_id)` constraint.                                    |
| Worker crashes during ingestion             | Partial ingestion corrupts index           | Make ingestion **idempotent** using `chunk_hash` + `UPSERT`.                                               |
| Transcript API fails                        | External dependency unreliable             | Implement **retry with exponential backoff** + **dead-letter queue**.                                      |
| Embedding API fails                         | Pipeline halts                             | Queue retry + fallback embedding provider or local model.                                                  |
| Query latency too high                      | Search must be interactive                 | Parallel **vector + BM25**, cache query embeddings, tune vector index.                                     |
| Vector similarity returns irrelevant chunks | Embeddings imperfect                       | Implement **two-stage retrieval**: candidate retrieval + **reranker**.                                     |
| Too many chunks from same video             | Poor UX                                    | Deduplicate by **best chunk per video**.                                                                   |
| Query cost increases with traffic           | Embeddings expensive                       | Cache query embeddings in Redis.                                                                           |
| Poor search quality                         | Hard to debug                              | Maintain **evaluation dataset** and compute retrieval metrics.                                             |
| Multi-language queries                      | Many videos not English                    | Use **multilingual embeddings**.                                                                           |
| Ingestion backlog grows                     | Workers can't keep up                      | Horizontal worker scaling via queue system.                                                                |
| Query spikes                                | API overload                               | Add **rate limiting + autoscaling**.                                                                       |
| Need observability                          | Hard to debug production issues            | Metrics + logs + tracing.                                                                                  |

| Metric                     | Meaning                                   | Why Important               |
| -------------------------- | ----------------------------------------- | --------------------------- |
| Recall@K                   | Correct result appears in top K           | Measures retrieval coverage |
| Precision@K                | Fraction of top results that are relevant | Measures result quality     |
| MRR (Mean Reciprocal Rank) | How high the correct result ranks         | Measures ranking quality    |
| nDCG                       | Ranking quality with graded relevance     | Used in search systems      |
| Hit Rate                   | Did we return a relevant result           | Simple effectiveness metric |
