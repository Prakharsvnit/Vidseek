------------------------------------------




sessionmaker

Creates a Session factory.

A Session represents a conversation with the database.

Example operations done through session:

SELECT

INSERT

UPDATE

DELETE

declarative_base

Creates a base class for your ORM models.

Create database engine
engine = create_engine(DATABASE_URL)

Creates the SQLAlchemy engine.

It:

manages DB connections

manages connection pool

sends SQL queries to PostgreSQL

Example internally:

engine → connection pool → postgres

Create session factory
SessionLocal = sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine
)

This creates a session generator.

bind=engine

Tells SQLAlchemy:

All sessions use this engine
autocommit=False

Means:

You must manually commit changes

Example:

db.add(user)
db.commit()

This prevents accidental writes.

autoflush=False

SQLAlchemy normally auto-syncs changes before queries.

Disabling autoflush gives more control.

Example flush:

Create Base class
Base = declarative_base()

This is the base class for all models.

Example:

class User(Base):

Later:

Base.metadata.create_all(engine)

This creates database tables.

Database dependency for FastAPI
def get_db():

This is a FastAPI dependency.

It provides a database session per request.

Create session
db = SessionLocal()

Creates a new database session.

Think:

HTTP request → DB session

Yield session
yield db

yield gives the session to the API route.

Example route:

def get_users(db: Session = Depends(get_db)):

Finally close session
finally:
    db.close()

This ensures:

Session always closes
Connection returns to pool

Example API request:

POST /users
